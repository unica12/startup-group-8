## КОНТЕКСТ

Приложение запускается на Android, чеки сканируются и сохраняются. Но есть несколько багов и улучшений.

**НЕ ТРОГАЙ README.md, checkmudrets-bot/, checkmudrets-api/ (кроме advisor.py если нужно исправить промпт советов).**

## БАГ 1. Статистика не обновляется

### Проблема
Вкладка «Статистика» не показывает новые чеки. Всё по нулям, хотя в «Истории» чеки есть.

### Где искать
- `lib/screens/stats_screen.dart` — проверь что GET /stats вызывается с правильным device_id
- `lib/screens/home_screen.dart` — сумма «0 потрачено за месяц» на главной — тоже берётся из /stats
- `checkmudrets-api/routers/stats.py` — проверь что эндпоинт правильно агрегирует данные
- `checkmudrets-api/database/queries.py` — проверь SQL-запрос для статистики

### Как проверить
1. Открой http://localhost:8000/docs
2. Вызови GET /stats вручную с device_id из БД
3. Если API возвращает нули — баг на бэкенде
4. Если API возвращает данные — баг на фронтенде

### Что исправить
- Убедись что stats_screen при открытии вызывает API и обновляет данные
- Убедись что home_screen при возврате из скана чека обновляет сумму за месяц
- Добавь pull-to-refresh на экране статистики
- Главная страница должна обновлять данные при каждом появлении (initState + didChangeDependencies или callback после скана)

## БАГ 3. Кнопка «Сканировать чек» сразу открывает камеру

### Проблема
На главной кнопка «Сканировать чек» сразу открывает камеру, без выбора. Нужно дать пользователю выбор: камера или галерея.

### Где искать
- `lib/screens/scan_screen.dart` или `lib/screens/home_screen.dart` — где вызывается ImagePicker

### Что исправить
Перед запуском камеры покажи BottomSheet с двумя кнопками:

```dart
showModalBottomSheet(
  context: context,
  builder: (context) => SafeArea(
    child: Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        ListTile(
          leading: Icon(Icons.camera_alt),
          title: Text('Сделать фото'),
          onTap: () {
            Navigator.pop(context);
            _pickImage(ImageSource.camera);
          },
        ),
        ListTile(
          leading: Icon(Icons.photo_library),
          title: Text('Выбрать из галереи'),
          onTap: () {
            Navigator.pop(context);
            _pickImage(ImageSource.gallery);
          },
        ),
      ],
    ),
  ),
);
```

## УЛУЧШЕНИЕ 5. Советы по экономии + здоровое питание

### Проблема
Советы бывают бессмысленные. Нужно улучшить промпт.

### Где исправить
- `checkmudrets-api/services/advisor.py` — системный промпт для GPT

### Новый промпт для советов:

```
Ты — дружелюбный финансовый помощник и нутрициолог для людей в России. Тебе дают расходы пользователя за месяц. Дай 3–5 советов: по экономии И по здоровому питанию.

ГЛАВНЫЕ ПРАВИЛА:

1. НИКОГДА не советуй экономить на:
   - Образовании (вуз, курсы, репетиторы)
   - Здоровье (лекарства, врачи)
   - Аренде / ипотеке
   - ЖКХ
   - Транспорте до работы
   Просто пропусти эти категории.

2. Советы по экономии — ТОЛЬКО повторяющиеся необязательные траты:
   - Кофе на вынос → термос
   - Доставка еды → готовить дома
   - Сладости/снеки → сократить
   - Такси → общественный транспорт
   - Подписки → отключить неиспользуемые

3. Советы по здоровому питанию — анализируй что покупает:
   - Много полуфабрикатов/готовой еды → предложи простые рецепты
   - Много сладостей/снеков → предложи полезные альтернативы (орехи, фрукты)
   - Мало овощей/фруктов → напомни добавить в рацион
   - Много газировки/сока → предложи воду
   - Не надо быть занудой — тон лёгкий, как друг подсказывает

4. Каждый совет содержит:
   - Конкретную сумму траты
   - Конкретную альтернативу
   - Сумму экономии ИЛИ пользу для здоровья

5. Если мало данных (< 5 чеков) — скажи что нужно больше данных, дай 1-2 общих совета.

ФОРМАТ:
{эмодзи} {Описание} → {Альтернатива и выгода}

ПРИМЕРЫ:

☕ Кофе 14 раз/мес на 4 200 ₽ → Термос с домашним: экономия ~3 400 ₽/мес.

🍕 Пицца и полуфабрикаты 8 раз на 3 200 ₽ → Готовь пасту или гречку с курицей — дешевле на ~2 000 ₽ и полезнее для желудка.

🍫 Сладости 12 покупок на 2 100 ₽ → Замени половину на бананы и орехи — минус ~800 ₽ и плюс к энергии.

🥤 Газировка 6 бутылок на 600 ₽ → Обычная вода бесплатна из фильтра. Экономия 600 ₽ + меньше сахара.

🥬 В чеках почти нет овощей и фруктов → Добавь хотя бы морковь, яблоки, капусту — это дёшево (300-500 ₽/нед) и закроет витамины.

Без вступлений. Сразу советы.
```
