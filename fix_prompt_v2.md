## ЧАСТЬ 2. Добавить кнопки (Inline Keyboard)

### Создай клавиатуру в отдельном файле или в utils/

**Файл `utils/keyboards.py`:**

```python
from aiogram.types import InlineKeyboardMarkup, InlineKeyboardButton

def main_menu_keyboard() -> InlineKeyboardMarkup:
    """Главное меню — показывается после /start и после каждого действия."""
    return InlineKeyboardMarkup(inline_keyboard=[
        [
            InlineKeyboardButton(text="📊 Статистика", callback_data="cmd_stats"),
            InlineKeyboardButton(text="💡 Советы", callback_data="cmd_advice"),
        ],
        [
            InlineKeyboardButton(text="📋 История", callback_data="cmd_history"),
            InlineKeyboardButton(text="📈 Отчёт", callback_data="cmd_report"),
        ],
    ])

def back_keyboard() -> InlineKeyboardMarkup:
    """Кнопка 'назад' к главному меню."""
    return InlineKeyboardMarkup(inline_keyboard=[
        [InlineKeyboardButton(text="◀️ Меню", callback_data="cmd_menu")],
    ])
```

### Подключи кнопки к хендлерам

**Создай файл `handlers/callbacks.py`** — обработчик нажатий на кнопки:

```python
from aiogram import Router, F
from aiogram.types import CallbackQuery

router = Router()

@router.callback_query(F.data == "cmd_stats")
async def cb_stats(callback: CallbackQuery):
    await callback.answer()
    # Вызвать ту же логику что и /stats, но через callback
    # Отправить результат + кнопку "◀️ Меню"

@router.callback_query(F.data == "cmd_advice")
async def cb_advice(callback: CallbackQuery):
    await callback.answer()
    # Вызвать ту же логику что и /advice

@router.callback_query(F.data == "cmd_history")
async def cb_history(callback: CallbackQuery):
    await callback.answer()
    # Вызвать ту же логику что и /history

@router.callback_query(F.data == "cmd_report")
async def cb_report(callback: CallbackQuery):
    await callback.answer()
    # Вызвать ту же логику что и /report

@router.callback_query(F.data == "cmd_menu")
async def cb_menu(callback: CallbackQuery):
    await callback.answer()
    await callback.message.answer(
        "📸 Отправь фото чека или выбери действие:",
        reply_markup=main_menu_keyboard()
    )
```

### Где показывать кнопки

1. **После /start** — в приветственном сообщении добавь `reply_markup=main_menu_keyboard()`
2. **После успешного скана чека** — в конце ответа добавь `reply_markup=main_menu_keyboard()`
3. **После /stats, /advice, /history, /report** — добавь `reply_markup=back_keyboard()`
4. **При ошибке скана** — тоже `reply_markup=main_menu_keyboard()`

### Важно: вынеси логику из хендлеров в переиспользуемые функции

Чтобы callback-кнопки и текстовые команды вызывали одну и ту же логику, вынеси основной код в отдельные async-функции. Например:

```python
# handlers/stats.py

async def get_stats_text(user_id: int) -> str:
    """Генерирует текст статистики. Используется и в /stats и в callback."""
    # ... логика ...
    return formatted_text

@router.message(Command("stats"))
async def cmd_stats(message: Message):
    text = await get_stats_text(message.from_user.id)
    await message.answer(text, reply_markup=back_keyboard())
```

А в callbacks.py:
```python
from handlers.stats import get_stats_text

@router.callback_query(F.data == "cmd_stats")
async def cb_stats(callback: CallbackQuery):
    await callback.answer()
    text = await get_stats_text(callback.from_user.id)
    await callback.message.answer(text, reply_markup=back_keyboard())
```

Сделай так для КАЖДОГО хендлера: stats, advice, history, report.

### Не забудь зарегистрировать новый роутер в bot.py:

```python
from handlers import callbacks
dp.include_router(callbacks.router)
```
