# Лендинг ЧекМудрец

Сайт, бот, API и приложение хранятся в одном репозитории unica12/startup-group-8.
Код сайта — папка docs. Изменения подготовлены в ветке landing-redesign.

## Опубликовать через GitHub

1. Убедиться, что ветка landing-redesign загружена в этот репозиторий и содержит папку docs.
2. Открыть Settings → Pages.
3. В Source выбрать Deploy from a branch.
4. Выбрать ветку landing-redesign и папку /docs, затем Save.
5. Дождаться успешной публикации. GitHub покажет адрес сайта.

Для настройки Pages нужны права администратора или сопровождающего репозитория. Если Settings недоступны, попросить владельца выполнить шаги 2–4.

Ожидаемый адрес без собственного домена: https://unica12.github.io/startup-group-8/ . До успешной публикации адрес может не открываться.

Это позволяет опубликовать сайт из отдельной ветки без изменения main. Позже можно объединить изменения в main и переключить Pages на main /docs. Публикуется только папка docs, а не код API или бота.

## Метрика

Используется уже созданный счётчик 112876432. Новый счётчик не нужен.

Перед сбором статистики в настройках счётчика заменить dicee38.github.io/landing/ на unica12.github.io/startup-group-8/ . Проверить, что включено принятие данных только с нужного адреса.

В разделе целей создать цели типа JavaScript-событие:

| Идентификатор | Что считаем |
| --- | --- |
| cta_click | Переход к блоку участия в тестировании |
| telegram_click | Переход в https://t.me/unq_33 |
| demo_open | Переход к демонстрации бюджета |
| budget_interaction | Изменение ползунка или выбор сценария |

Клик по Telegram не подтверждает отправку сообщения. В отчёте называем его переходом, а реальные обращения считаем отдельно. В параметры целей личные данные не передаются.

После публикации проверить загрузку счётчика и тестовый визит в Метрике. Цели нужно создать в интерфейсе Метрики вручную — код сайта их автоматически не создаёт.

Неделю наблюдений отсчитывать после проверки работы счётчика. Зафиксировать посетителей, визиты, источники, устройства, отказы и конверсию в переход в Telegram. Собственные тестовые визиты отделить от реального трафика. Данные демонстрации и демо-отзывы не являются результатами исследования.

## Просмотр на компьютере

Из корня репозитория выполнить:

```sh
python -m http.server 8765 --directory docs
```

Открыть http://localhost:8765 . Для просмотра без команд можно открыть docs/index.html в браузере.

## Проверка перед публикацией

Проверены синтаксис JavaScript, ссылки на разделы, отсутствие заглушек и наличие подключаемых файлов. Визуальная проверка в браузере и фактическая доставка событий в Метрику ещё не выполнены. До публикации проверить сайт на компьютере и телефоне, ползунок и кнопки Telegram.
