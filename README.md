# 2. 🔄 User Flow (сценарии пользователя)

## 📌 Основной сценарий

1. Пользователь открывает Telegram-бота  
2. Загружает фото чека  
3. Система обрабатывает изображение  
4. Пользователь получает:

# 3. 📊 Метрики MVP

## ⭐ North Star Metric

**Количество чеков, обработанных на пользователя в неделю**

👉 Почему:
- отражает реальное использование продукта  
- напрямую связано с ценностью  
- влияет на удержание  

---

## 📈 Продуктовые метрики

1. **Conversion to first чек**
   - % пользователей, загрузивших первый чек  
   - Цель: ≥ 60%

2. **Retention Day 7**
   - % пользователей, вернувшихся через 7 дней  
   - Цель: ≥ 25%

3. **Среднее количество чеков на пользователя**
   - Показывает глубину использования  

4. **Доля пользователей, читающих рекомендации**
   - Показывает ценность аналитики  

5. **Время до первого действия**
   - Насколько быстро пользователь начинает использовать продукт  

---

## 💰 Бизнес-метрики (гипотеза)

- Конверсия в платную подписку ≥ 5%  
- CAC < LTV  

---

## 🧮 Правила расчёта метрик

- Conversion = (пользователи с ≥1 чеком / все пользователи) × 100%  
- Retention = (вернувшиеся пользователи / новые пользователи) × 100%  
- Среднее чеков = общее количество чеков / количество пользователей
