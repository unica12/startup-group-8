# 3. 📊 Unit-экономика (упрощённая)

## 📌 Допущения

- Средний чек подписки: **149 руб/мес**  
- Конверсия в платящих: **5%**  
- Средний срок жизни: **6 месяцев**  

---

## 🧮 Расчёты

### 💰 LTV (Lifetime Value)

LTV = 149 × 6 = **894 руб**

---

### 📉 CAC (стоимость привлечения)

Предположим:
- реклама / трафик = 50 руб за пользователя  

👉 CAC = **50 руб**

---

### 📊 Юнит-экономика

| Метрика | Значение |
|--------|---------|
| ARPU | 149 руб |
| LTV | 894 руб |
| CAC | 50 руб |
| LTV/CAC | 17.8 |

---

## ✅ Вывод

- Экономика положительная  
- Есть запас для масштабирования  
- Можно увеличивать маркетинг  

---

# 4. 📈 Финансовая модель (упрощённая)

## 📌 Допущения

- 5 000 пользователей через 3 месяца  
- 50 000 пользователей через 12 месяцев  
- Конверсия в платящих: 5%  

---

## 📊 Доходы

### Через 3 месяца:
- 5 000 × 5% = 250 платящих  
- 250 × 149 = **37 250 руб/мес**

---

### Через 12 месяцев:
- 50 000 × 5% = 2 500 платящих  
- 2 500 × 149 = **372 500 руб/мес**

---

## 💸 Расходы (примерно)

| Статья | Сумма |
|-------|------|
| Серверы | 30 000 руб |
| AI / OCR API | 50 000 руб |
| Маркетинг | 100 000 руб |
| Прочее | 20 000 руб |

👉 Итого: **~200 000 руб/мес**

---

## ⚖️ Точка безубыточности

Необходимое количество платящих:

200 000 / 149 ≈ **1343 пользователя**

---

## 📌 Вывод

- Проект может выйти в плюс при:
  - ~27 000 пользователей (при 5% конверсии)  
- Масштабируемость высокая  
- Основной драйвер роста — маркетинг
