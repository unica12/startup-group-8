# Неделя 10. Бизнес-модель и финансовая модель

## 1. Цель этапа

На десятой неделе команда сформировала бизнес-модель продукта и провела финансовые расчёты. Основной задачей стало понять, как продукт будет зарабатывать, сколько стоит его разработка и когда он выйдет в плюс.

Цели этапа:
- описать бизнес-модель и логику монетизации
- сформулировать гипотезы монетизации и выбрать приоритетную
- рассчитать затраты на разработку и поддержку
- оценить unit-экономику и окупаемость

---

## 2. Бизнес-модель

Продукт монетизируется через модель **Freemium** — базовый функционал бесплатно, расширенные возможности по подписке.

| Уровень | Что включено | Цена |
|--------|-------------|------|
| Бесплатный | Загрузка чека, базовый анализ, общие советы | 0 ₽ |
| Premium | Подробная аналитика, история покупок, персональные советы по финансовой грамотности | 199 ₽/мес |

Логика выбора модели:
- низкий порог входа привлекает пользователей без барьера оплаты
- ценность Premium очевидна после нескольких использований бесплатной версии
- подписочная модель даёт предсказуемый регулярный доход

---

## 3. Гипотезы монетизации

Были рассмотрены три варианта:

1. **Подписка Premium** — фиксированная плата за расширенный функционал *(выбрана как приоритетная)*
2. **Партнёрские рекомендации** — советы по экономии с аффилиатными ссылками на магазины и сервисы
3. **B2B-интеграции** — аналитика покупательского поведения для ритейла (долгосрочная перспектива)

На текущем этапе реализуется только подписочная модель как наиболее простая в проверке.

## 5. Unit-экономика

Ключевые параметры:

| Показатель | Значение |
|-----------|---------|
| Цена подписки | 199 ₽/мес |
| Комиссия RuStore | 5% |
| Чистый доход с 1 подписчика | ~189 ₽/мес |
| Конверсия в платный тариф (гипотеза) | 5% |
| Стоимость привлечения (CAC) | 0 ₽ (органика, сарафанное радио) |
| Окупаемость 1 пользователя (payback) | 1 месяц |

При 1 100 пользователях и 5% конверсии — около 55 платящих пользователей к шестому месяцу, что даёт ~10 395 ₽ выручки в месяц.
