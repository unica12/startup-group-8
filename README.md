# 📌 Этап B. Ценностное предложение и PMF

## 🚀 Проект: ЧекМудрец

**ЧекМудрец** — это Telegram-бот, который помогает пользователю автоматически учитывать расходы по фото чеков и получать персональные рекомендации по экономии.

---

# 1. 💎 Value Proposition (ценностное предложение)

## 🎯 Проблема

Большинство людей не контролируют свои расходы и сталкиваются со следующими трудностями:

- ❌ Не понимают, куда уходят деньги  
- ⏱ Тратят 10–15 минут в день на ручной учёт  
- 🧾 Теряют чеки или не могут их использовать  
- 📉 Не получают реальных рекомендаций по экономии  

👉 В результате пользователи теряют значительную часть дохода без понимания причин.

---

## 💡 Решение

Мы создаём продукт, который полностью автоматизирует процесс учёта расходов:

- 📸 Пользователь фотографирует чек  
- 🤖 Система распознаёт данные (OCR + ИИ)  
- 📊 Автоматически разбивает на категории  
- 💡 Даёт персональные рекомендации  

---

## ⭐ Уникальная ценность продукта

- ⚡ Очень быстро: 3–5 секунд на обработку  
- 🤖 ИИ-советы, а не просто статистика  
- 📱 Не нужно отдельное приложение — всё в Telegram  
- 💸 Реальная польза: экономия до нескольких тысяч рублей  

---

## 🧩 Почему пользователи выберут нас

- Минимум действий → максимум результата  
- Нет необходимости вручную вводить данные  
- Простой и понятный интерфейс  
- Видимый финансовый результат (экономия)

---

# 2. 👤 Портрет клиента (Customer Profile)

## 🎯 Основной сегмент

- Студенты и молодые специалисты (18–30 лет)  
- Доход: низкий или средний  
- Активные пользователи Telegram  
- Не ведут учёт расходов или делают это нерегулярно  

---

## 🧠 Поведенческие характеристики

- Совершают импульсивные покупки  
- Не анализируют расходы системно  
- Предпочитают простые и быстрые решения  
- Избегают сложных финансовых инструментов  

---

## 😩 Боли пользователя

- "Деньги куда-то исчезают"  
- "Лень считать вручную"  
- "Не понимаю, где можно сократить расходы"  

---

## 🎯 Потребности

- Быстро понимать свои траты  
- Получать понятные рекомендации  
- Экономить без лишних усилий  
- Иметь простой инструмент без сложной настройки  

---

# 3. 🔬 Гипотезы ценности и каналов привлечения

## 💡 Гипотезы ценности

1. Пользователям важна **автоматизация учёта расходов через фото чеков**  
2. Пользователи ценят **экономию денег больше, чем сам учёт**  
3. Пользователи готовы платить за **персональные рекомендации**  
4. Telegram — удобная и привычная платформа для взаимодействия  

---

## 📣 Гипотезы каналов привлечения

1. **TikTok / Reels / Shorts**
   - Контент: "куда уходят деньги", "разбор чеков"
   - Вирусный формат коротких видео  

2. **Telegram-каналы**
   - Финансы, экономия, лайфхаки  
   - Возможность нативной интеграции  

3. **Реферальная система**
   - Пользователи приглашают друзей  
   - Вирусный рост  

4. **Студенческие сообщества**
   - Университеты  
   - Чаты и группы  

---

# 4. 🛠 Backlog MVP

## 🔑 Основные функции MVP

- 📸 Загрузка фото чека  
- 🔍 OCR-распознавание текста  
- 📊 Извлечение данных (позиции, суммы, дата)  
- 🗂 Категоризация расходов  
- 📈 Отображение статистики  
- 💡 Генерация базовых рекомендаций  
- 🤖 Telegram-бот интерфейс  

---

## ⚙️ Критерии минимальности (MVP)

MVP считается готовым, если:

- Пользователь может загрузить чек без ошибок  
- Система корректно извлекает ключевые данные  
- Пользователь видит структуру своих расходов  
- Есть хотя бы одна полезная рекомендация  
- Весь процесс занимает минимальное время  
- Продукт полностью работает через Telegram  

---

## 🎯 Приоритет функций

1. Распознавание чеков  
2. Корректность данных  
3. Простота использования  
4. Генерация рекомендаций  

---

# 5. 🧪 План тестирования гипотез

## 🔍 Что проверяем

- Пользователи готовы загружать чеки  
- Пользователям интересны рекомендации  
- Пользователи возвращаются в продукт  
- Есть ли ценность в автоматизации  

---

## 🔧 Как проверяем

- Запуск MVP Telegram-бота  
- Привлечение 100–500 пользователей  
- Сбор обратной связи (опросы, интервью)  
- Анализ поведения пользователей  

---

## 📊 Метрики

### 📈 Продуктовые метрики

- Conversion to first чек ≥ 60%  
- Retention Day 7 ≥ 25%  
- Среднее количество чеков на пользователя  

---

### 💰 Бизнес-метрики

- Конверсия в платную подписку ≥ 5%  
- CAC < LTV  

---

### ❤️ Поведенческие метрики

- Доля пользователей, читающих рекомендации  
- Доля пользователей, возвращающихся в продукт  
- Частота использования  

---

## ✅ Критерии успеха

- Пользователи регулярно используют продукт  
- Есть повторные действия (retention)  
- Пользователи отмечают ценность рекомендаций  
- Появляются первые платящие пользователи
