# Неделя 6. Разработка MVP (Telegram-бот с нейросетью)

## 1. Цель этапа

Основной задачей шестой недели стала реализация MVP на основе ранее сформированного backlog — Telegram-бота с подключённой нейросетью для анализа фото чеков.

Цели этапа:
- разработать рабочую версию бота
- реализовать ключевой пользовательский сценарий
- подключить нейросеть для анализа изображений
- подготовить продукт к тестированию

---

## 2. Реализованный функционал

В рамках разработки были реализованы следующие компоненты:

- приём фотографии чека от пользователя в Telegram
- передача изображения в нейросеть (vision-модель) для анализа
- извлечение из ответа нейросети: суммы трат и перечня категорий товаров
- сохранение данных о каждой покупке в локальном хранилище бота (файл/память)
- формирование ответа пользователю с итогами чека
- генерация советов по экономии на основе выявленных категорий трат
- сбор и выдача статистики расходов за неделю и месяц

---

## 3. Технические решения

При разработке были приняты следующие решения:

- Telegram Bot API для взаимодействия с пользователем
- vision-модель нейросети для распознавания и анализа фото чеков
- хранение данных пользователя в файле / памяти бота (без отдельной БД)
- серверная обработка изображений и формирование ответов

Основной акцент был сделан на скорости разработки и работоспособности сценария.

---

## 4. Основные сложности

В процессе разработки были выявлены следующие проблемы:

- нестабильность распознавания текста на некоторых видах чеков
- различия в форматах и качестве изображений чеков
- необходимость корректной обработки ошибок при неудачном анализе
- не всегда точная категоризация товаров нейросетью

---

## 5. Результат

К концу недели был получен:
- рабочий Telegram-бот с подключённой нейросетью
- реализованный полный базовый сценарий: фото → анализ → ответ → советы
- возможность просматривать статистику трат за неделю / месяц
- готовый продукт для тестирования на пользователях

---

## 6. Промежуточный вывод

MVP позволяет:
- загрузить фото чека и получить автоматический анализ
- узнать сумму и категории расходов без ручного ввода
- получить советы по экономии
- отслеживать статистику трат за период

Следующий этап — тестирование продукта на реальных пользователях.
