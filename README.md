## 🧠 Краткое описание

**ЧекМудрец** — это сервис для автоматического анализа расходов по фото чеков с помощью ИИ и генерации персональных рекомендаций по экономии.

👉 MVP реализован в виде Telegram-бота  
👉 Финальный продукт планируется как мобильное приложение с публикацией в RuStore  

---

## 🎯 Проблема

- Люди не понимают, куда уходят деньги  
- Ручной учёт занимает много времени  
- Чеки теряются или не используются  
- Нет инструментов с реальными рекомендациями  

---

## 👤 Целевая аудитория

- Студенты и молодые специалисты (18–30 лет)  
- Пользователи мобильных приложений и Telegram  
- Люди с низким и средним доходом  
- Те, кто не ведёт учёт расходов  

---

## 💡 Предположения (гипотезы)

- Людям важнее экономия, чем сам учёт  
- Пользователи не хотят вводить данные вручную  
- Фото чека — самый удобный способ учёта  
- Для MVP достаточно Telegram-бота  
- Для масштабирования потребуется мобильное приложение  

---

## ⚠️ Продуктовое решение по платформе

В условиях возможных ограничений доступа к Telegram в РФ:

- MVP реализуется в виде Telegram-бота, так как:
  - быстрее разрабатывать  
  - проще тестировать гипотезы  
  - ниже затраты  

- Финальная версия продукта будет:
  - 📱 мобильное приложение  
  - 📦 публикация в RuStore  
  - 🚀 независимость от сторонних платформ  

👉 Таким образом, Telegram используется как инструмент валидации, а не финальная платформа.
