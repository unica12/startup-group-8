# Неделя 9. Метрики и аналитика продукта

## 1. Цель этапа

На девятой неделе команда перешла к формированию системы оценки эффективности продукта. После разработки и перехода к мобильному приложению стало необходимо определить, каким образом будет измеряться его ценность и развитие.

Цели этапа:
- определить ключевую метрику продукта
- выбрать дополнительные продуктовые метрики
- описать способы их расчёта
- сформировать базовую систему аналитики

---

## 2. Подход к выбору метрик

При выборе метрик команда ориентировалась на:
- ценность продукта для пользователя
- применимость к текущему этапу разработки
- простоту измерения

Было принято решение не усложнять систему метрик и сосредоточиться на базовых показателях, актуальных для мобильного приложения.

---

## 3. North Star Metric

В качестве основной метрики была выбрана:

**Количество обработанных чеков**

Данная метрика отражает:
- реальную активность пользователей
- использование ключевого функционала приложения
- фактическую ценность, которую получает пользователь

---

## 4. Дополнительные метрики

Были определены следующие показатели:

| Метрика | Описание |
|--------|--------|
| Retention | возврат пользователей в приложение |
| Conversion | доля пользователей, загрузивших хотя бы один чек |
| Engagement | частота использования приложения |
| Error Rate | доля чеков, которые не удалось корректно обработать |

---

## 5. Описание метрик

**Retention:**
показывает, возвращаются ли пользователи после первого использования приложения

**Conversion:**
отражает, сколько установивших приложение пользователей действительно используют основной функционал

**Engagement:**
характеризует частоту взаимодействия с приложением — насколько регулярно пользователи сканируют чеки

**Error Rate:**
показывает качество работы нейросети — долю чеков, которые не были корректно распознаны или обработаны

---

## 6. Использование метрик

Метрики планируется использовать для:
- оценки качества и востребованности продукта
- выявления проблем с распознаванием и UX
- принятия решений о приоритетах доработки
- отслеживания роста аудитории

---

## 7. Ограничения текущего этапа

На данном этапе:
- полноценная аналитическая система в приложении ещё не реализована
- сбор данных осуществляется ограниченно
- метрики оцениваются приближённо
