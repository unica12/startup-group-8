## 1. Краткое описание компании

ООО «ЧекМудрец» — стартап в сфере финансовых технологий (FinTech), разрабатывающий мобильное приложение для автоматического учёта расходов. Основная функция — распознавание кассовых чеков по фотографии с помощью технологий искусственного интеллекта (GPT-4o-mini Vision) и предоставление персональных рекомендаций по экономии и здоровому питанию.

**Ключевые характеристики:**

| Параметр | Значение |

| Место регистрации | г. Москва, РФ |
| Дата регистрации | 2025 г. |
| Кол-во сотрудников | 3 человека (основатели-разработчики) |
| Доля ИТ-доходов | 100% |

**Продукты компании:**

- 📱 PWA приложение «ЧекМудрец»

## 2. Задание №1 — Проверка критериев ИТ-аккредитации

Анализ соответствия ООО «ЧекМудрец» базовым требованиям для получения государственной аккредитации ИТ-компании в Минцифры РФ.

### 2.1. Критерии аккредитации

| № | Критерий | Статус ООО «ЧекМудрец» | Соответствие | Примечание |
|:-:|---|---|:-:|---|
| 1 | Государственная регистрация в РФ | Зарегистрирована как ООО в г. Москва | ✅ | — |
| 2 | Основной ОКВЭД из перечня ИТ | 62.01 — Разработка компьютерного ПО | ✅ | Входит в перечень Минцифры |
| 3 | Отсутствие налоговой задолженности | Задолженность отсутствует | ✅ | Справка ФНС |
| 4 | Компания не в стадии ликвидации / банкротства | Действующая компания | ✅ | — |
| 5 | Доля ИТ-доходов ≥ 30% | 100% доходов от ИТ-деятельности | ✅ | Послабление для компаний < 3 лет |

### 2.2. Выявленные проблемы и пути устранения

**Проблема 1.** Молодая компания без финансовой истории — Минцифры может запросить дополнительные пояснения о планируемой деятельности.

> **Решение:** подготовить подробное описание продуктов компании с демонстрацией работающего MVP (мобильное приложение и Telegram-бот), ссылку на репозиторий и техническую документацию.

**Проблема 2.** Отсутствие выручки на начальном этапе — требования к доле ИТ-доходов (≥ 30%) могут быть неприменимы, но нужно подтвердить, что вся деятельность — ИТ.

> **Решение:** для компаний младше 3 лет действуют послабления — достаточно иметь основной ОКВЭД из перечня ИТ-деятельности и подтвердить ведение деятельности в области разработки ПО.

**Проблема 3.** Средняя заработная плата должна быть не ниже средней по стране (или по региону). На начальном этапе зарплаты могут быть ниже порога.

> **Решение:** для компаний, зарегистрированных менее 3 лет назад, критерий по средней заработной плате не применяется. Это даёт временное окно для масштабирования.

**Проблема 4.** Использование зарубежного API (OpenAI GPT-4o-mini) может вызвать вопросы в контексте импортозамещения.

> **Решение:** использование зарубежного API для обработки данных не противоречит требованиям аккредитации. В перспективе — миграция на отечественные LLM (GigaChat, YandexGPT) для снижения зависимости и повышения конкурентоспособности.
