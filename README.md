# Неделя 7. Тестирование MVP

## 1. Цель этапа

На седьмой неделе команда сосредоточилась на тестировании Telegram-бота с реальными пользователями.

Цели этапа:
- проверить удобство использования продукта
- оценить качество работы нейросети на реальных чеках
- выявить ошибки и недостатки
- собрать обратную связь
- принять решение о дальнейшем развитии продукта

---

## 2. Организация тестирования

Тестирование проводилось на ограниченной группе пользователей, соответствующих целевой аудитории.

Пользователям предлагалось:
- запустить бота и отправить реальный чек
- оценить корректность распознавания суммы и категорий
- ознакомиться с советами по экономии
- запросить статистику трат
- дать развёрнутую обратную связь

---

## 3. Результаты тестирования

В ходе тестирования были выявлены следующие проблемы:

- нейросеть не всегда корректно распознавала чеки низкого качества или нестандартного формата
- категоризация товаров была неточной в части случаев
- ответы бота воспринимались как недостаточно понятные
- советы по экономии казались слишком общими
- отсутствие визуализации статистики снижало ценность продукта

---

## 4. Обратная связь пользователей

Основные замечания:
- хотелось бы более точный анализ чека
- советы по экономии слишком обобщённые, хочется конкретики
- неудобно работать через Telegram — лучше отдельное приложение
- нет наглядной статистики (диаграммы, графики)

---

## 5. Выводы

- ценность продукта подтверждается: идея нравится пользователям
- качество распознавания и анализа требует улучшения
- формат Telegram-бота ограничивает UX
- для полноценного продукта необходимо мобильное приложение

---

## 6. Промежуточный результат

Команда:
- провела тестирование MVP
- получила обратную связь от пользователей
- сформировала список улучшений
- приняла решение о переходе к разработке мобильного приложения

Следующий этап — разработка мобильного приложения для Android и iOS.
