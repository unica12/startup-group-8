# Неделя 6. Разработка MVP (Telegram-бот)

## 1. Цель этапа

Основной задачей шестой недели стала реализация MVP на основе ранее сформированного backlog.

Цель этапа:
- разработать рабочую версию продукта
- реализовать ключевой пользовательский сценарий
- подготовить продукт к тестированию

---

## 2. Реализация функционала

В рамках разработки были реализованы следующие компоненты:

- обработка входящих сообщений
- прием изображений
- интеграция с модулем распознавания текста
- извлечение ключевых данных из чека
- формирование ответа пользователю

---

## 3. Технические решения

При разработке были приняты следующие решения:
- использование Telegram Bot API
- серверная обработка изображений
- базовая логика анализа данных

Основной акцент был сделан на скорости разработки и работоспособности.

---

## 4. Основные сложности

В процессе разработки были выявлены следующие проблемы:
- нестабильность распознавания текста
- различия в форматах чеков
- необходимость обработки ошибок

---

## 5. Результат

К концу недели был получен:
- рабочий Telegram-бот
- реализованный базовый сценарий
- возможность тестирования продукта

---

## 6. Промежуточный вывод

MVP позволяет:
- загрузить чек
- получить базовую информацию
- протестировать гипотезу ценности

Следующий этап — тестирование продукта на пользователях.
